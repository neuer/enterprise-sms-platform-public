为什么这样收

  • 好看的登录页把认证源压成配角。前几稿都在为选择发明结构，所以不像登录。
  • 我们不能按邮箱域名自动分流，所以借 AWS / 阿里云：必须人选，但仍是单栏里的轻切换。
  • 浅色分段是已否决的模式开关，只放在对照里，避免又走回去。

这一稿

  • 回到 360px 单卡、单栏。表单重新当页。
  • 认证源是两个名字加间隔点，选中用短下划线。无底槽、无印、无列表。
  • 输入改回标签在上，和主流控制台一致，也方便以后落 Element Plus。
  • 仅一源时收成一行名字，不留切换。
  • 只交原型，不改 Vue / CSS / 测试。

规则仍旧

  • 每次登录只提交一个 provider_code，失败不自动改走另一源。
  • 默认仍选中服务端返回的第一项。
  • 深色、无插画、错误内联、全中文。
