为什么这样收

  • 仅一源时把切换收掉，栏就塌了，卡片上半截空一截，所以显得薄。
  • 两种认证源是平台固定目录，不是运行时才发明出来的。关掉一路，也不该假装另一路不存在。
  • 未开通的那个要一眼能看出来「在，但不能用」，不能做成和未选中一样淡。

这一稿

  • 本地 / AD 始终并排。选中仍是短下划线，说明仍写当前源。
  • 未开通的名字留在原位，透明度压低，底下写「未开通」。点它只提示，不改 provider_code。
  • 不再使用「当前唯一可用认证源」那句只读确认。
  • 只交原型，不改 Vue / CSS / 测试。

规则仍旧

  • 每次登录只提交当前已开通且选中的一个 provider_code，失败不自动改走另一源。
  • 默认仍选中服务端返回的第一项已开通源。
  • 深色、360px 单卡、无插画、全中文。
