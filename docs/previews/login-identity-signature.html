为什么改

  • 现网来源条复用了配置页的对象语言：LOCAL/AD 印、单选圆、沉底卡片。登录因此像在改系统配置。
  • 分段开关是模式，来源条是对象。登录要的是「这次以谁的身份进入」，两者都不贴。
  • 两步先选来源仍不作为默认：日常多一次点击，而且把凭据藏起来。

变更（待评审）

  • 认证源改成署名列表：名称即界面，说明只出现一次。
  • 选中项用 verdi 与字重，建议复用登录页衬线（品牌字第三处例外）；不画卡片、印、单选圆。
  • 仅一个认证源时收成「以本地账号进入控制台」，不留孤条。
  • C 的一句署名更静，但另一源不够显眼。主推仍是 A。
  • 本期只交原型与截图，不改 Vue / CSS / 测试。

不动

  • 每次登录只提交一个 provider_code，失败不自动改走另一源。
  • 默认仍选中服务端返回的第一项。规则 31 的硬约束是「失败不回退」，不是「禁止预选」。
  • 账号框占位仍区分「账号 / 企业 AD 账号」；展示名仍用服务端 name。
  • 深色令牌、400px 单卡、鸾印、无插画；错误内联，不弹窗。
