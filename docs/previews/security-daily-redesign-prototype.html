    设计决策（相对现网的变更点）

  • 页头副文写明机制事实：固定 08:00（北京时间）汇总前一自然日、页面只展示脱敏结构化证据、Resend Key 保存后不回显；右侧操作保留 配置邮件 / 立即生成 / 刷新 三枚，页头不放页级计数。前端
  • 概览卡保留：运行状态卡（状态 tag + 机制说明 + 下次调度）与八格事实格（调度 / 收件人数只展示数量 / 发件域名 / 最近日报状态 / 最近成功生成 / 最近成功投递 / 最近失败 / Beat 配置）维持现有信息与视觉，为页级专属样式。现有
  • 五个筛选器收进方案 A 单行检索条：报告日期起止两枚 date 输入经「查询」按钮生效（先校验起止先后）；安全状态 seg（全部/正常/关注/高风险）、生成状态 seg（全部/生成中/已生成/生成失败/数据不可用）、投递状态 seg（全部/未投递/等待 mailer/投递中/已投递/投递失败）点选即重查，直接映射现有 status / generation_status / delivery_status 参数；条底细字写明服务端分页过滤与脱敏边界。el-card 外壳与卡头筛选区退役，结果面板化并入 reply-results 共享组。前端
  • 常驻规则条 slim 三格：脱敏边界（只展示脱敏结构化证据，手机号与密钥永不进入界面）、配置例外（Resend Key 明文仅存专用配置并同步独立 mailer，审计只记 configured 状态与数量，Key 不回显）、投递语义（独立 mailer 投递并回写状态、查询时惰性同步、失败可重试、同日重复投递有幂等保护），与 user-rules 同组常驻。前端
  • 底栏合并口径与分页：「共 N 条 · 每页 20」+ 分页并入 reply-pagination 共享组；原 total > 20 才渲染分页的限制退役，与回调任务、用户与角色同语言。前端
  • 三处确认拆后果正文与审计细字：「立即生成」（新增一条记录不覆盖历史、生成后立即投递、处理中投递会拒绝重生成）与「手动投递 / 重试投递」（邮件正文只来自已脱敏结构化报告、状态由独立 mailer 回写）改 h() VNode 确认框；成功 toast 统一带「本次操作已记入审计」，配置保存同样带上。前端
  • 空态两行规约三变体 + 错误条带重新加载：未启用（引导配置邮件）/ 配置不完整（区分投递器与收件人）/ 筛选无结果（带清除筛选）；列表加载失败 el-alert 内联重试。配置邮件 dialog 与纯文本预览 dialog 维持现状。前端
  • 行为与既有 testid 保留：行点击与「查看详情」开抽屉、「处理失败」入口、抽屉全部区块、配置校验与清空 Key 语义不变；新增三组 seg、日期、查询/重置与清除筛选 testid；移动端断点对齐 760px。前端
SCREEN A · 默认列表（admin 视角 · 概览卡 + 单行检索条 + 常驻规则条 + 日报台账全量要素）

脱敏边界

页面只展示脱敏结构化证据，手机号与密钥永不进入界面；详情与预览同样只是只读投影。

配置例外

Resend Key 明文仅存专用配置并同步独立 mailer，审计只记 configured 状态与收件人数量；Key 保存后不回显。

投递语义

投递由独立 mailer 执行并回写状态，页面查询时惰性同步；投递失败可重试，同日重复投递有幂等保护。

    契约核对

  • 概览 GET /api/v1/web/admin/security-daily/overview 与列表 GET .../reports 参数 date_from / date_to / status / generation_status / delivery_status / page / page_size 全部沿用；三组 seg 直接映射现有枚举参数，报告日期经「查询」按钮生效并先校验起止先后，不新增查询参数。现有
  • 详情 GET .../reports/{id}、纯文本预览 GET .../reports/{id}/preview、配置 GET / PUT .../config、立即生成 POST .../generate（新增一条记录不覆盖历史；该日存在处理中投递请求时 409 拒绝重生成）、手动投递 POST .../reports/{id}/send 与重试 POST .../reports/{id}/retry（同日重复投递幂等）全部维持现状；四个写操作均有 @audited 留痕。现有
  • 页面只展示脱敏结构化证据与收件人数量；Resend Key 为明确产品例外——明文仅存专用 sys_config 并同步独立 mailer 的 resend.json，界面不回显，审计只记 configured 状态与数量。现有
  • 零契约变更：不新增端点、不新增字段、不加导出；页面 admin 专属（路由 /security-daily），路由守卫与导航维持现状。现有
