    设计决策（相对现网的变更点）

  • 筛选收进单行检索条：关键词 220px + 认证源 / 角色 / 状态三组 seg，与黑名单、敏感词、应用管理同一胶囊语言；seg 点选即重查，关键词走「查询」按钮；口径说明沉条底。filter-grid 旧栅格在本页退役（审计页另行处理）。前端
  • 撤下页头「有效 X/Y · 本地 Z」摘要：原数字只统计当前页 items，翻页后即失真，易被误读为全量口径；总数沉底栏「共 N 名用户 · 每页 20」，页头不再放任何页级计数。若未来需要全量统计，须新增汇总端点（ext），本期不做。前端
  • 用户名 / 密码规则条保留但瘦身：FR-18a 要求两类规则常驻显示，由独立卡片改为检索条下的 slim 双格条；密码规则文案仍来自 GET /auth/password-policy，接口短暂不可用时保留安全缺省文案。现有
  • 台账表格账本化：th 规范、双行单元格与行悬停对齐批次 / 黑名单语言——主行姓名（13px/600）+ mono 用户名，副行认证源与凭据 tag；角色列 = 角色 tag + 来源副行（本地固定 / 跟随 AD / 人工覆盖）；状态列 = 账号 tag + 同步态圆点 + mono 时间；停用行整行 opacity .55。前端
  • 三抽屉统一骨架：抽屉头 = 标题 + mono 端点行（POST /local、PUT /{id}/role、POST /{id}/password/reset），抽屉底 = 左侧机制 / 审计脚注 + 右侧按钮；创建抽屉保留提交前即时校验（用户名 3–64 位字符集、密码长度 / 字符类别 / 不含用户名，与服务端同规则），重置密码抽屉复用同一骨架不再单独立屏。前端
  • 确认框拆后果正文与审计细字：停用 / 重置密码 / 强制下线均如实告知后果（无法登录、既有会话立即失效、下次登录必须改密）+ 审计细字（只记操作人与对象 account_id）；toast 统一带「本次操作已记入审计」。现有
  • 空态两行规约双变体：空库引导「创建本地账号」，筛选无结果引导「清除筛选」。前端
  • 行为与 testid 全量保留：创建 / 角色 / 重置 / 停用 / 下线既有 data-testid 不改名；移动端 760px 双渲染（表格 ↔ 卡片）与 44px 触达目标维持现状。前端

    契约核对

  • 列表 GET /api/v1/web/admin/users 参数 keyword / provider_code / role / status / page / page_size，响应 UserPage{items,total}；keyword 服务端匹配 login_name / display_name / dept。三组 seg 直接映射现有三个枚举参数，不新增查询参数。现有
  • 创建 POST /local（username / display_name / dept / role / temporary_password writeOnly）；用户名规范化 3–64 位小写字符集，密码策略以 GET /auth/password-policy 下发为准、服务端权威校验，前端仅做同规则提交前拦截。现有
  • 角色 PUT /{account_id}/role（role, role_override）：本地账号恒 override=true；AD 恢复跟随即 override=false，恢复目标角色由服务端按 external_role_mapping 计算，界面只展示来源组快照、不预览计算结果。现有
  • 状态 PUT /{account_id}/status、重置 POST /{account_id}/password/reset、下线 POST /{account_id}/sessions/revoke：全部按稳定 account_id 定位；写操作分别落审计 local_account_create / role_override / account_status_change / local_password_reset / force_logout。现有
  • 错误如实展示：404 NOT_FOUND、409 LAST_ADMIN_PROTECTED / ACCOUNT_SOURCE_CONFLICT / STATE_CONFLICT、422 PASSWORD_POLICY_VIOLATION、403 停用本人；页面不另造错误文案。现有
  • 零契约变更：不新增端点、不新增字段、不做全量统计计数（撤下的页头摘要即为此口径纠错）、不加导出；页面 admin 专属（PRD 附录 A #14），路由守卫与导航维持现状。现有
