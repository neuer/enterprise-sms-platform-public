    设计决策（相对现网的变更点）

  • el-tabs + el-card 外壳退役：改与系统参数同组的自定义页签条（告警记录 / 回调任务 / 原始报文 / uncertain / unmatched / 任务健康 / 队列恢复 / Outbox 投递），横向溢出可滚动，键盘左右切换，?tab= 深链与首访 lazy 语义不变；八个面板脱离 el-card 直接落地。前端
  • 四块筛选区统一方案 A 单行检索条：告警=类型关键词 220px + 等级 seg（全部/info/warn/crit 点选即重查）+ 时间范围 + 查询/重置；原始报文=来源 seg（全部/报告/回复）+ 处理状态 seg（全部/待重放/已处理）点选即重查，无查询按钮；unmatched=手机号 mono 250px + 时间范围 + 查询/重置 + 右侧导出区（授权明文勾选 + 导出对账）；Outbox=状态 seg（全部+六态）点选即重查。条底细字如实写明过滤边界与隐私事实。服务端分页过滤不变，不新增查询参数。前端
  • 常驻规则条两格：守卫与审计（重放/手动触发/死信重推/队列恢复均二次确认并写审计；uncertain 只读，仅 reconcile 可迁移，禁止自动重发）+ PII 边界（原始报文只展示无 PII 元数据；手机号仅在内存转 HMAC；明文导出需二次认证）。与 user-rules/config-rules 同组。前端
  • 页头计数沉底：面板标题右侧的「共 N 条」计数撤下，各表页脚统一「共 N 条 · 每页 20」+ 分页（并入 reply-pagination 共享组）；任务健康无分页，计数收进面板副题。前端
  • 结果面板化：表格与移动端卡片统一包进 ops-results 面板（并入 reply-results 共享组）；既有 testid、表格列、移动端双渲染全部保留。前端
  • 四处确认拆后果正文与审计细字：报文重放 / 任务手动触发 / 死信重推 / 队列恢复全部改 h() VNode 确认（ops-confirm-dialog/ops-confirm-audit 并入 sign-* 共享组）；成功 toast 统一带「本次操作已记入审计」。现有
  • 回调任务页签不动：嵌入的 CallbackView 维持既有紧凑工具栏（filter-toolbar 契约仍由 CallbackView 承载），本规范不覆盖。现有
  • 行为与 testid 全量保留：ops-alert/raw/uncertain/unmatched/outbox-pagination、alert-detail-*、ops-unmatched-phone/ops-unmatched-search、download-unmatched-export、force-resume、outbox-stats、outbox-retry-*、导出 step-up 密码流程与 loadToken 竞态防护均不变。前端

    契约核对

  • 告警 GET /admin/alerts（page / alert_type / level / start / end）、原始报文 GET /admin/raw-logs（page / source / processed）、unmatched GET /admin/unmatched-reports（page / phone / start / end）、Outbox GET /admin/outbox/events（page / state）：全部维持服务端分页过滤，seg 只是既有查询参数的映射，不新增任何契约字段。现有
  • 重放 POST /admin/raw-logs/{id}/replay、手动触发 POST /admin/jobs/{job_name}/trigger、死信重推 POST /admin/outbox/{id}/retry、队列恢复 POST /admin/queue/resume?force=：四个写入口均保留二次确认与审计，请求体与状态机不变。现有
  • 导出 POST /admin/unmatched-reports/export + GET /reports/export/{id} + 明文下载 X-Export-Step-Up 密码二次认证流程不变；手机号仍只在内存转 HMAC。现有
  • 回调任务页签为嵌入的 CallbackView，沿用独立紧凑工具栏与契约，本原型不覆盖。现有
  • 零契约变更：不新增端点与字段、不服务端化过滤、不改 openapi.yaml；?tab= 深链、首访 lazy 渲染与 loadToken 竞态防护维持现状。现有
