为什么另起一稿

  • 前几稿都在同一张 400px 卡里换控件：分段、来源条、署名列表、一句署名。卡还在，认证源就还是表单附件。
  • 登录不是「先填一个设置项再登录」。它是从某一种身份走进控制台。
  • 控件减到只剩两个名字，空了，就会显得未完成。这一稿用整页结构承担视觉，而不是再画一层盒子。

这一稿

  • 整页对开。左墙放品牌与身份，右院只放凭据。
  • 选中项用右侧 verdi 门槛线标出来，不画印、单选圆、沉底卡片。
  • 说明只出现在当前身份下面。凭据贴在门槛右侧，不在空院正中。
  • 输入改成底线，不再用沉底方框。提交文案改成「进入」，对应门槛。
  • 仅一源时，左墙只留一个名字，不假装还能再选。
  • 只交原型。不改 Vue / CSS / 测试。

规则仍旧

  • 必须显式选择一个 provider_code，失败不自动改走另一源。
  • 默认仍选中服务端返回的第一项。
  • 深色、无插画、错误内联、全中文、不用感叹号。
  • 窄屏可叠成上下，390px 不横向滚动。
